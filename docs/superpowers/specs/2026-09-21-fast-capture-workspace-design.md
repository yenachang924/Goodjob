# 오늘 중심 탐색과 빠른 기록

## 목적

왼쪽에서 관리하는 활동을 한눈에 보고, 제목 입력과 Enter만으로 할 일을 연속 등록한다. 기존 기록·시간 측정·백업을 보존한다.

## 승인된 화면 방향

- 데스크톱 왼쪽에 빠른 기록, 오늘, 시간 기록, 수업/프로젝트/개인공부 트리, 미분류를 배치한다.
- 영역은 한 단계만 제공한다. 활동(기존 프로젝트 모델)이 영역 하나에 속하고 할 일은 활동의 영역을 상속한다.
- 영역은 접고 펼칠 수 있다. 선택 위치를 표시하고 접힘 상태를 기억한다. 작은 화면에서는 탐색창을 접어 본문 공간을 확보한다.
- 기본 화면은 오늘이다. 월간 캘린더 옆에 선택 날짜의 할 일을 표시하며 모바일에서는 세로로 배치한다.
- 캘린더의 작업 예정일과 마감일을 구분한다. 예정일 변경이 마감일을 바꾸지 않는다.
- 활동 화면은 실제 할 일 제목, 완료 체크, 시간 측정 버튼을 우선 표시한다. 진행률과 마일스톤은 보조 정보로 둔다.
- 기존 전체/프로젝트 중복 화면을 제거한다. 기존 시간 배치 기능은 오늘 화면에서 펼쳐 사용할 수 있도록 유지한다.
- 상단에 날짜와 타이머 접근점을 고정한다. 실행 중인 할 일, 경과 분·초, 종료 버튼을 표시한다. 시작할 때는 기존 할 일을 선택하며 동시에 하나만 측정한다.
- 큰 로그인 없는 로컬 모드 안내문은 제거한다. 저장 위치와 백업 안내는 작은 저장/백업 메뉴로 이동하고 클라우드 저장으로 오해하게 표시하지 않는다.
- 기존 Pretendard 폰트를 유지한다.

## 빠른 기록 동작

- 목록 안에 제목 입력란을 항상 제공한다. 제목만 필수이며 Enter로 저장한다.
- 한국어 IME 조합 중 Enter는 제출하지 않는다. 공백 제목과 중복 제출을 막는다.
- 저장 성공 후 제목을 비우고 입력란 포커스를 복원한다. 실패하면 입력 내용을 유지하고 오류를 표시한다.
- 활동 화면에서는 해당 활동에 자동 소속된다.
- 오늘 화면에서는 선택 날짜를 작업 예정일로 사용한다. 마지막 선택한 유효한 활동을 기본값으로 사용하고 없으면 미분류에 등록한다.
- 예상 시간, 마감일, 마일스톤은 등록 후 선택적으로 편집한다. 미정 시간을 임의로 30분 등으로 채우지 않는다.
- 하위 할 일은 부모 행 아래에서 같은 인라인 입력 방식으로 추가한다. 기존 1단계 하위 할 일 제한과 마일스톤 상속을 유지한다.
- 추가 버튼은 키보드를 쓰지 않는 사용자를 위해 함께 제공하지만 입력 후 Enter만으로도 완료된다.

## 데이터와 호환성

- 기존 프로젝트/할 일/세션 ID, 시간 기록의 시작·종료 타임스탬프, 로컬 저장 키와 동시 저장 충돌 보호를 유지한다.
- 프로젝트에 선택적 영역 필드를 추가한다. 누락된 기존 프로젝트는 미분류로 표시하고 사용자가 한 번에 영역을 지정할 수 있게 한다. 이름으로 영역을 강제 추정하거나 기존 프로젝트를 새로 복제하지 않는다.
- 소속 없는 빠른 기록은 예약된 미분류 활동에 연결한다. 미분류 활동은 첫 기록을 저장하는 같은 트랜잭션에서만 생성하며 빈 저장소 열기만으로 데이터를 쓰지 않는다.
- 할 일에 선택적 작업 예정일을 추가한다. 기존 날짜별 확정 계획도 오늘 목록에 반영하며 같은 할 일은 중복 표시하지 않는다. 마감일에만 해당하는 작업은 마감 표시로 구분한다.
- 예상 시간 0은 미정으로 허용하고 UI에는 숫자 0분 대신 미정으로 표시한다. 자동 시간 배치는 미정 작업을 0분 작업으로 채워 넣지 않고 예상 시간 입력 대상으로 안내한다.
- 기존 V2 백업과 데이터가 계속 읽히도록 선택적 필드와 검증을 확장한다. 새 필드도 내보내기/가져오기와 로컬 저장에서 보존한다.
- 수동 기록 시간은 `시간`과 `분`을 별도 숫자 입력란으로 제공한다. 예를 들어 1시간 30분은 내부에서 90분으로 합산하므로 사용자가 환산할 필요가 없다. 날짜 입력과 시작/종료 상세 편집을 유지한다.
- 시간은 0~24의 정수, 분은 0~59의 정수로 검증한다. 한쪽만 입력하면 다른 쪽은 0으로 처리하며 둘 다 비어 있거나 합계가 0분 또는 24시간을 초과하면 저장하지 않는다. 미래 시각과 기존 세션 중복 검증도 유지한다.
- 기존 기록을 열기만 하거나 기록 길이를 수정하지 않고 저장할 때 원래 타임스탬프와 초 단위 정밀도를 유지한다. 시간/분을 명시적으로 수정한 경우에만 입력한 길이를 적용한다.
- 기록 시간과 합계는 `1시간 30분`처럼 표시한다. 예상 시간은 기존 요청대로 분 단위를 유지한다. 실행 중 타이머는 시·분·초로 표시한다. 저장 오류·용량 초과·충돌 때 성공으로 표시하지 않는다.

## 이번 범위 밖

- Google 로그인, 새로운 클라우드 저장, Supabase 인증 연결 복구, 자동 기기 동기화는 이번 UI 구현과 분리한다. 로컬 데이터는 자동 업로드하지 않는다.
- 기록은 여전히 브라우저 저장소에 남으므로 사이트 데이터 삭제에 대비한 JSON 내보내기를 유지한다. 서버리스 영구 저장을 완료했다고 안내하지 않는다.
- 임의 깊이 폴더, 여러 영역 중복 소속, 새 캘린더 외부 연동, 사용자 데이터 삭제/이전은 하지 않는다.
- 검증 전 자동 배포하지 않는다.

## 검증 기준

1. 기존 V2 데이터/백업을 읽고 새 기록과 함께 재접속 후 보존한다.
2. 영역별 탐색과 접힘 상태, 미분류 이동, 활동 선택이 정상 동작한다.
3. 제목+Enter 연속 등록과 IME 입력이 정상 동작하고 실패 시 초안이 보존된다.
4. 예정일과 마감일, 확정 계획 중복, 예상 시간 미정 처리가 구분된다.
5. 상단 및 행 타이머가 단일 세션 규칙을 공유하며 기존 기록을 보존한다.
6. 수동 시간/분 분리 입력(1시간 30분, 분만 입력, 시간만 입력), 빈 값/0분/60분/24시간 초과 거부, 기존 초 정밀도 보존, 시간 합계, 백업 왕복, 동시 탭 충돌을 테스트한다.
7. 데스크톱과 모바일 실제 브라우저에서 탐색/입력/타이머/스크롤과 접근 가능한 레이블을 확인한다.
8. 단위·통합·E2E 테스트, 타입 검사, 프로덕션 빌드를 실행한다.

## 실행 단위

1. 데이터/검증: 영역, 미분류, 선택 예정일, 시간 미정 및 호환성 테스트를 먼저 작성한다.
2. 탐색/입력: 활동 트리와 재사용 가능한 인라인 입력을 구현한다.
3. 오늘/시간: 캘린더와 할 일 목록, 상단 타이머, 기록 시간의 시간/분 분리 입력을 연결한다.
4. 검증/리뷰: 기존 로컬·인증 회귀 테스트와 신규 UX 테스트를 수행하고 코드 리뷰를 반영한다.

## 확인 상태

사용자 승인 후 2026-09-21 로컬 구현을 완료했다. 단위·통합 테스트 104개, 로컬 데스크톱·모바일 E2E 26개, 클라우드 모의 서버 편집 회귀 E2E 20개가 통과했다. 타입 검사와 프로덕션 빌드가 성공했으며 모바일 최종 화면도 확인했다.

저장은 기존 브라우저 로컬 저장 방식을 유지한다. 실제 Supabase 데이터 변경, 클라우드 자동 백업, 커밋·푸시 및 Vercel 재배포는 수행하지 않았다.
