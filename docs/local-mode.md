# 로그인 없이 사용하기

배포된 [Goodjob](https://goodjob-web-blue.vercel.app/)의 기본 화면은 각 브라우저에 기록을 저장하는 로컬 모드입니다. Supabase 가입이나 별도 서버 설치가 필요하지 않습니다.

## 저장 위치와 주의점

- 프로젝트, 작업, 마일스톤, 시간 기록은 현재 브라우저 프로필의 이 사이트 저장소에 보관됩니다. 새로고침해도 유지됩니다.
- 다른 사람의 컴퓨터나 다른 브라우저에는 자동으로 공유되지 않습니다. 같은 컴퓨터에서 같은 브라우저 프로필을 함께 쓰면 기록도 함께 보입니다. 공용 컴퓨터에서는 사용을 피하세요.
- 브라우저 데이터 삭제, 시크릿 창 종료, 컴퓨터 고장으로 기록을 잃을 수 있습니다. 중요한 기록은 정기적으로 **내보내기**로 JSON 파일을 보관하세요. JSON에는 개인 기록이 그대로 들어 있으므로 안전한 위치에 저장하세요.
- 다른 컴퓨터에서는 동일한 웹사이트를 열고, 빈 워크스페이스에서 **가져오기**로 백업을 선택하세요. 기존 기록이 있으면 덮어쓰지 않습니다.
- `localhost`, `127.0.0.1`, 배포 주소는 각각 다른 저장소입니다. 일상 사용은 고정된 배포 주소 하나로 통일하세요.
- 최신 Chrome/Edge/Safari/Firefox의 HTTPS 페이지 또는 localhost에서 사용하세요. 안전한 다중 탭 저장 잠금을 지원하지 않는 환경에서는 저장을 차단하고 안내합니다.
- 여러 탭에서 수정한 경우 오래된 탭의 저장은 차단됩니다. 입력 내용을 따로 보관하고 '저장본 새로고침'으로 최신 데이터를 불러오세요.

## Vercel과 Supabase의 역할

Vercel은 앱 화면과 업데이트를 배포합니다. 로컬 모드의 프로젝트 기록은 Supabase나 워크스페이스 API로 전송되지 않습니다. 웹페이지 접속 자체의 일반적인 호스팅 요청은 발생합니다.

Supabase는 선택 사항인 **클라우드 모드**의 인증·저장 용도로 남아 있습니다. `/cloud`에서 기존 로그인을 사용할 수 있지만 기존 인증 장애가 해결됐다는 뜻은 아닙니다. 로컬과 클라우드 기록은 자동으로 합쳐지거나 동기화되지 않습니다. 기존 클라우드 기록은 삭제하지 않습니다.

인터넷 없이 설치해서 쓰는 PWA/데스크톱 앱은 아닙니다. 페이지를 처음 불러오려면 인터넷 또는 실행 중인 로컬 개발 서버가 필요합니다.

## 개발 서버로 실행하기

Node.js 22.13 이상이 설치된 컴퓨터에서 저장소 루트에 들어가 실행합니다.

```powershell
npm ci --include=dev
npm run dev
```

터미널에 표시된 주소를 여세요. 기본 로컬 모드에는 `.env.local`이나 Supabase 설정이 필요 없습니다. 터미널을 닫으면 개발 서버도 종료됩니다. 직접 실행하는 사용자끼리 기록이 공유되지는 않습니다.
